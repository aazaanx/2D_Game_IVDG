Pumpkin Dungeon - By Aazan, Vigo and Ian

Escape the dungeon as a pumpkin, face monsters, collect coins all in an attempt to escap ethe dungeon into freedom. Use arrow keys to move around, spacebar to attack monsters, and E to interact with coins. Each monster gets progressively harder and must be defeated in order to escape. Are you up to the challenge? 

Tip: Don't Die!
